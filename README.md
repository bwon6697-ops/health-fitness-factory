# Health & Fitness Factory 💪

A modern, responsive gym website for Health & Fitness Factory located in Mehnagar, Uttar Pradesh, India.

## 🏋️ About

Health & Fitness Factory is a premium fitness center in Mehnagar offering personalized workout plans, expert trainers, and modern equipment. This website serves as our digital presence for members to manage their fitness journey.

### For Members
- 🔐 Secure user authentication
- 📊 Personalized dashboard with BMI, calories, and workout tracking
- 💪 Exercise library with animated demonstrations
- 🍎 Meal logging and nutrition tracking
- 💧 Water intake tracker
- 📈 Progress monitoring
- 🔔 Real-time notifications from admin
- 👤 Profile management with photo upload

### For Owner (Admin Panel)
- 📊 Overview dashboard with key statistics
- 👥 Complete members management
- 💬 Contact messages inbox
- 🔔 Send notifications to members
- 💰 Fees management and reminders
- 📈 Analytics and statistics
- ⚙️ Settings management

### Public Pages
- 🌟 Animated intro page
- 🏠 Beautiful landing page
- 💰 Membership plans and pricing
- 🔢 Free BMI calculator
- 📞 Contact form
- 💪 Public exercise library

## 🛠️ Technology Stack

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Authentication:** Firebase Authentication
- **Database:** Firebase Realtime Database
- **Image Storage:** Cloudinary
- **Fonts:** Google Fonts (Bebas Neue, Rajdhani, Orbitron)
- **Hosting:** GitHub Pages
